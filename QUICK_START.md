# ⚡ Quick Start Guide (5 Minutes)\n\n**Never used this before?** Start here!\n\n---\n\n## 🪟 Windows Users\n\n### Quick Setup (All-in-one)\n\n1. **Download the project** → Extract to a folder\n2. **Double-click `setup.bat`** → Automatic setup ✨\n3. **When done, open Command Prompt** in the project folder:\n   ```cmd\n   python app.py\n   ```\n4. **Open browser** → http://localhost:5000\n5. **Export a WhatsApp chat** and upload!\n\n**Stuck?** → See INSTALLATION.md or read the README\n\n---\n\n## 🍎 macOS Users  \n\n### Quick Setup\n\n1. **Open Terminal** and navigate to project folder\n2. **Run:**\n   ```bash\n   bash setup.sh\n   ```\n3. **Launch app:**\n   ```bash\n   python app.py\n   ```\n4. **Open browser** → http://localhost:5000\n5. **Export WhatsApp chat** and upload!\n\n**Python 3 not found?** Install via Homebrew:\n```bash\nbrew install python@3.11\n```\n\n---\n\n## 🐧 Linux Users\n\n### Quick Setup\n\n1. **Install Python (if needed):**\n   ```bash\n   sudo apt-get install python3.11 python3.11-venv\n   ```\n\n2. **Run setup:**\n   ```bash\n   bash setup.sh\n   ```\n\n3. **Launch app:**\n   ```bash\n   python app.py\n   ```\n\n4. **Open browser** → http://localhost:5000\n\n---\n\n## 📱 How to Export WhatsApp Chat\n\n### Android 📱\n- Open WhatsApp → Group/Chat\n- Tap **⋮** (three dots) → **More** → **Export Chat**\n- Choose **Without Media** → Save to computer\n\n### iPhone 📱\n- Open WhatsApp → Group/Chat\n- Tap **Contact Name** → **Export Chat**\n- Choose **Without Media** → Save to computer\n\n---\n\n## 🎯 What Can You Do?\n\n✅ **Upload & Analyze** — Parse WhatsApp exports\n✅ **See Statistics** — Messages, trends, activity patterns\n✅ **Sentiment Analysis** — Positive, Neutral, Negative breakdown per sender\n✅ **Live Predictions** — Type any message and see instant sentiment\n✅ **Beautiful Charts** — Interactive visualizations & word clouds\n✅ **ML Models** — Trains on your data for custom predictions\n\n---\n\n## 🔧 Common Issues\n\n**\"Python not found\"**\n- Windows: Reinstall with \"Add Python to PATH\" ✓\n- macOS: `brew install python@3.11`\n- Linux: `sudo apt-get install python3.11`\n\n**\"Module not found\"**\n- Windows: Run `setup.bat` again\n- macOS/Linux: Run `bash setup.sh` again\n\n**\"Port 5000 in use\"**\n- Change port in app.py: `app.run(port=5001)`\n\n**More help?** → See INSTALLATION.md\n\n---\n\n## currently\n\n---\n\n## 🎮 Command Line Usage\n\n```bash\npython main.py path/to/chat.txt\n```\n\nOutputs results to `results/` folder\n\n---\n\n## 🛑 To Stop the App\n\nPress **Ctrl+C** in the
